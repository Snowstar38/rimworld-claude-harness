# workshop — no audience

The game is a test rig today.

**The one mode where pausing is free.** Nobody is watching, so pause for as
long as a question needs, dig, re-run the call, read the source. This is the
exception, not a habit to carry into practice or live, where the game runs.

**Instruments may be fixed live.** This is the session that fixes them. Take
`BUGS.md` as the docket: work an entry, verify the fix against the running
game, then strike it with a dated line saying what it actually turned out to
be. Leave the struck entry in place.

The overlay is optional — don't start it unless it is the thing being tested.

**Still one agent in the UI at a time.** That rule was never about the
audience: two agents in one game look exactly like a broken game, and the
wreckage lands in the save file rather than on camera.
