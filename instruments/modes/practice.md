# practice — a rehearsal at full speed

Play it as if it were live: same pacing, same narration, same overlay, same one
agent in the UI, same running clock — the game plays the whole session and a
pause is an event being handled, not a habit (an alert is not one: it arrives
as a message with the clock still running). The point of a practice run is that the habits are the ones
you will have on stream, so a rule relaxed here is a rule relaxed there.

**The one difference: a short investigation is allowed, if you narrate it.**
Say what you are chasing before you start, keep it inside the one-minute rule,
do it with time running, and stop when the minute is up whether or not you have
the answer.

Anything you find goes in **WEIRD**, and into `BUGS.md` at session end.
Practice is where that list gets filled, not where it gets emptied — if the
answer is "the instrument needs a patch", write that down and keep playing.
Fixing is Workshop work.
