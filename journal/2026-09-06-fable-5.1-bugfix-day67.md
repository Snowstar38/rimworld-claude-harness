## The turn-length fix

The forks were ending turns at 2:30 because their harness boilerplate says
"execute one directive, then stop", and the day-60 rewrite of `hands.md` had
dropped the paragraph that overrode it. `hands.md` now opens with a section
saying the directive is a six-minute turn, the brief is where to start and
not a checklist that ends it, Hands has no clock and must not estimate one,
and the system's five-minute warning is the signal to wrap up. A message from
M mid-turn is work inside the turn. Only a human pause, an unstartable
clock or `TaskStop` ends a turn early. The PLAYBOOK's turn loop says the same
from the Core's side, and a human message packet now carries a one-line
reminder of it.

## What the builders found

- **Terrain glyphs (M's wanted item).** Natural rock, smoothed rock,
  ore veins and constructed walls each have their own glyph now, and ore
  veins carry a letter per ore, so compacted machinery reads as `k` instead
  of the same `%` as steel.
- **Floor ambiguity** was the bridge listing a dropdown designator beside its
  own active child under the same label, so which label collided changed as
  floors were placed. One resolution path now prefers the row that accepts
  cells, for dry-run, `--do` and `labels` alike.
- **Phantom SHORT** was the companion counting only storage-zone stock
  against a blueprint's full cost. Live tonight it reads SHORT on paved tile
  against one steel in the colony, which is true.
- **Vanishing item ids** were stacks merging or being eaten, not a wrong id
  form. `inv.py` now says so and names the cell address as the durable one.
- **`inv.py components`** failed because RimWorld's labels are singular; the
  four components were there.
- **`hunt` by thingId** failed because the id lives in the `animals` block
  the query never asked for.
- **The world map** is a toggle button, not a tab window, so it cannot be
  opened through the bridge at all. A new `home/world` tool reads the tile
  off the world grid instead; live it returned biome, temperatures, a 30-day
  growing period and three settlements within fifteen tiles.
- **`order.py menu` could click** because it fell back to a raw right-click,
  which dispatches the default action. It is read-only now.
- **FORCE_PAUSED with no window** was the companion refusing on a paused
  TickManager. Start now refuses only for a named long event or a real
  force-pausing window.
- **`ask.py`** crashed on emoji in cp1252, and an emoji in a question or a
  choice label would have killed the Tk window too.

New commands: `world.py`, `act.py allow` (unforbid via the Allow gizmo),
`act.py tame`, `order.py force` (M's right-click-to-prioritise),
`buildings.py gizmo` (select, list, fire in one process; turret Uninstall),
