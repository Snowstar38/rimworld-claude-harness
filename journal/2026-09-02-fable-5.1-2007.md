## The thing that was actually wrong

Four of the six bugs were the same bug wearing different clothes, and it is
worth naming because it will happen again:

**An absent JSON key and a null value are indistinguishable in Python, and this
stack has been reading the first as the second for weeks.**

- `home/list_pawns {equipment:true}` — the option **was never implemented**. The
  SDK binder (`AnnotatedExtensionCapabilityProvider.BindArguments`) walks the
  method's *declared* parameters and silently discards any argument name that
  has no match. So the call was accepted, the argument thrown away, the key
  absent, and `.get()` returned `None`. "This build cannot answer" and "she has
  no gun" arrived as the same four characters. Lucas was believed armed for five
  sessions on that.
- `home/get_cells_plus` — same binder, worse outcome. It declared only
  `{x,z,width,height}`, so `{x0,z0,x1,z1}` was dropped and the ints defaulted to
  zero: a **successful 1x1 scan of cell (0,0)**, fogged and empty, `success:
  true`. And `passable` was never emitted at all while `walkable` was emitted
  only when *false*, under the file's own omit-falsey rule — so a walkable cell
  reported neither key.
- `home/list_buildings` — `count: 11`, 8 positions. Two accumulators for one
  fact: `Count++` on every instance, `Positions.Add` only up to a cap of 8.
- `promotedOut` had been promised by the class remarks and the `[ToolResponse]`
  string **since the tool was written**, and no code ever emitted it.

So: the payload documented a field the code did not produce, and the reader
supplied a plausible value for the silence. Every fix today moved in the same
direction — emit the field always, make the count derive from the list, and
refuse loudly with the arguments you actually parsed instead of returning a
confident empty answer.

## Two bug lines that were wrong about themselves

- **`build.py --do` refusing a Wall** was not the C# tool at all. `build.py` had
  an unconditional guard applying "a real placement needs exactly one rotation"
  to every def. The payload has carried `rotatable` since this morning; the
  wrapper never asked.
- **"The potato plant alert did not stop the run"** — it is not an alert. It is a
  transient message, `NegativeEvent`, it *does* reach Hands and it *does* stop a
  `run.py` turn, and there is a live capture in `INSTALL.md:495` proving it. The
  intent behind the line was right about the neighbouring thing: minor **alerts**
  reached nobody, because three filters independently agreed on
  `priority == "High"` — and `AlertPriority` is *ordered* (Medium < High <
  Critical), so an equality test was silently dropping **Critical** too.

## Rungs

- `SendFeedback`-worthy or not, this one is real: **a refused TCP connect on
  loopback takes ~2.03s on this machine**, not the ~1ms it costs on Linux. So
  "overlay server down" and "overlay server hanging" are indistinguishable here
  — the socket timeout always fires first. A note in `overlay_client.py` had
  blamed that delay on IPv6 fallback; it is this instead. Retries there are now
  budgeted in real elapsed seconds rather than counted.
- `Verse.StandardLetter` **derives from** `RimWorld.ChoiceLetter`, so every
  ordinary letter reports a `choices[]` array. Any isinstance-flavoured "is this
  a decision" test keeps the whole stack. Match on the full type name.
- Letters must be aged by **wall clock, not `ageTicks`**: the game is paused for
  most of a turn, so a letter can sit on screen for minutes and age zero ticks.

not just clutter — *"that one implies they need to do extra verification on
everything just because ONE TIME we had a tool sending bad info and that was
fixed"*, and the agent playing this colony already over-tests. The rule outlives
its cause and compounds into pausing.

`PLAYBOOK.md`: 24,940 → ~21,000 characters, zero dates, and every command intact.

**And the principle that reorganised the roadmap**, hers: *"i don't want the agent
to HAVE to call tools 5x, or having 5 tools listed in documentation for them to
be calling."* The cost of a tool is **surface area, not milliseconds** — five doc
entries are five chances to skip one. The audit had declined WANTED 10 on speed
grounds; that was answering a question nobody asked, and the decline is corrected
in place. `home/list_pawns` with five opt-in blocks is the house pattern, and
