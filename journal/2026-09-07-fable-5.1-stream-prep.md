## What was actually wrong

**Twenty minutes at the door** (the freshest errata) was a stale runtime binding, and the builder found the real cause in `state\runtime-hook-errors.log`: SessionStart did fire and did try to bind, but the previous session's `claude.exe` was still alive for a few more seconds, so `bind()` refused, the refusal went to a log nobody reads, the old host died, and every fork's claim then blamed the hook. Now the hook re-binds a dead binding at Core's next tool call, `stream.py bind-check --repair` does it by hand, the claim refusal says missing / dead (pid named) / mismatch / live, and a Hands is told it cannot fix it and must hand back. Later in the session I made a same-host rebind legal, because `--repair` binds whatever session id it has on record and a mismatch on our own process is not a second session. Live: the setup STATUS block printed `!! binding : DEAD` naming pid 33188 the moment the game came up, and `--repair` bound it. One trap: run under Git Bash's `timeout` wrapper the repair cannot see its Claude ancestor; run it bare.

**The windowless force pauses** that each cost a `play.py start` were the daily autosave. Decompiled: `TickManager.ForcePaused` ORs the window stack with `LongEventHandler.ForcePause`, and the autosaver queues a long event every in-game day. The watcher stopped on any force pause. Now a force pause with no window is waited out (20 s) and logged as `long_event` then `force_pause_cleared`; a real window still stops and is named; `play.py start` retries through one. Live: the autosave cleared in 0.3 s and play never stopped.

**Negative notifications stopped the clock.** Found live, not in the reports: the first run stopped 30 s in on *Cotton plant has died because of cold*. The day-55 errata had the same shape (a gift, a departing visitor, a lost inspiration, each a restart). Only threats, deaths, decisions and unknown classes stop now; negative letters and messages are non-stopping `notification_new` rows, and a negative one wakes a parked Hands. Live on the second run: a dead cotton plant, a dead potato plant and *Longhoff is no longer inspired* all arrived without a stop.

**Letters piled up** because the sweep lived in watch.py and run.py and supervised play never called it — M asked about this mid-session. The play service now sweeps standing announcements every 30 s. Live: seven letters, the newest 20 game hours old, gone within the first sweep.
