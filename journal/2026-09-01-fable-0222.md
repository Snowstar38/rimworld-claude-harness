What shipped:

- **trunk → core, end-to-end** (Opus agent 1). The wire value
  (`phase: "core"`) changed in the same pass as both ends — stream.py sends,
  server.py normalizes, overlay.html renders "Turn N, core writing the
  summary". Persisted `state.json` migrated in place (it restores on server
  start, so a stale "trunk" would have survived). 18 tracked files; left
  untouched: journals, mail, RimWorld saves (literal tree trunks), and
  M's own quoted words — rewriting inside her quotation marks would
  misquote her.
- **The Hands prose/tone guide** (Opus agent 2): hands.md's "Narrating to the
  stream" grew 27 → 94 lines — where the comedy actually is (plan-vs-outcome
  gap, pawns undignified but held with affection, understatement scaled to
  disaster), the handback summary as the most-read thing the fork writes
  (story-in-one-breath, not a changelog), goals text as a promise a viewer can
  watch fail. Four lines only on the Core side — M's containment rule.
  Sample pair: *"DISASTER! Fire everywhere!"* → *"The kitchen is on fire. The
  kitchen is where we keep the food."*
- **Her new standing rule, arrived mid-session**: nothing regularly loaded
  into context carries unnecessary historical details. The prose agent swept
  hands.md (all attributions, dates, and the old-name aside from the morning's
  rename gone); I swept PLAYBOOK.md by hand. The distinction I applied and
  told her: **provenance goes, freshness stays** — "(Lucas, Aug 31)" is
  history, but a date qualifying an empirical claim that can go stale is
  load-bearing. Recorded in memory `M.md` in her words.
- **The name bouncer** (her ask, mid-session): `scrub()` in server.py replaces
  her name with "M" at every ingestion door — event text, chat names, goals,
  status label — plus once more on state.json restore for anything written
  before the bouncer existed. Word-boundary, any case, possessives come out
  "M's", "Mitchell"/"Mdith" pass untouched. No prompt anywhere needs a
  name rule now; the server is the single enforcement point. `NAMES` tuple is
  the place to add spellings.
- **The phone-relay listener** (Opus agent 3): `listener.bat` + `listener.md`
  (a genuinely tiny brief: sit idle, relay her words verbatim via
  `python relay.py "msg"`, add `--pause` only for drop-everything) +
  `relay.py` (posts `{kind:"human"}` to the overlay BEFORE pausing; lazy rim
  import so a dead bridge can't block the message). Wired into setup.py right
  after `ensure_game()` — idempotent via a command-line probe
  (`CommandLine -like '*listener.bat*'`), chosen over window titles because
  Claude Code rewrites the console title. **`claude --remote-control
  errata-listener` exists as a launch flag** — no human `/rc` needed, and the
  name must be passed explicitly or the flag swallows the initial prompt as
  the session name.
- **Tested live at 2:20am**: overlay restarted on new code, listener launched,
  M sent a message from her phone — it arrived through Remote Control →
  listener → relay.py → overlay human panel, already scrubbed to "M's". The
  full chain works. NEXT-SESSION.md retired (git has it).
