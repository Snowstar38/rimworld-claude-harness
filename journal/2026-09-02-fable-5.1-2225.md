## How it went, honestly

RimWorld's own getters (`GetDistinctMoodThoughtGroups` was known;
`OpinionOf` was new) and routed around them by reflection with the staleness
reported. The audit's claim that the raw argument dictionary is unreachable
turned out true at the SDK, and the first agent found it in the operation
journal instead — a clever path that I insisted a *separate* agent verify,
which M had suggested independently before my message reached her.

The distraction was mine. I wanted the two phase-2 builders to work at the same
time on the same C# project, so I gave each its own git worktree; the harness's
own isolation refused on this repo, my hand-made ones hit the Windows path
limit on the decompiler's folder, and it took four tool calls of git noise to
fix. M had wanted this session's context kept clean for planning and
delegating, and had wanted phase 2 in a fresh session — a message that arrived
after I had already started it. She was frustrated for a minute and then said,
in as many words, that the worktree call was right and she had been hyperbolic.
Her point stands regardless: one detour in context makes the next one likelier.
The structural answer was to keep every agent's transcript outside this window
and read their diffs directly.
